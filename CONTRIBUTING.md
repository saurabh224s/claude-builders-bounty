# Contributing

This repository is a community bounty board for Claude Code and AI tooling.

## Bounty workflow

1. Read the complete issue and acceptance criteria.
2. Confirm the bounty is still open and follow its documented claim process.
3. Implement only the agreed scope.
4. Run reproducible validation.
5. Open a PR linking the issue and describing the validation.

Payment is governed by the bounty provider and the terms attached to the specific issue. A merged PR does not independently guarantee payment unless the published bounty terms say so.
